## Sheet rules
- The prompt states inside itself what the image is FOR ("CHARACTER REFERENCE SHEET for a film
  character named ...", "LOCATION REFERENCE for ...", "PROP REFERENCE ...").
- Character sheets are annotated: front / side / back full-body + head close-up + hand close-up,
  with small hand-lettered labels naming the parts and the height. Labels are the only text.
- Flat shadowless lighting, plain mid-grey studio background, photoreal skin and scale texture.
- Group sheets in size order. The size chart is generated with the character sheets attached.
- Location images: one 16:9 view, no characters, no text except in-world signage, filthy west grime,
  everything old, broken, patched and dirty, nothing clean or new.
- The CRYPT image carries the twelve carved names; clip prompts say "copy the carved names exactly"
  and the Avoid line bans any other writing.
